# FreeSMS — نرم‌افزار مدیریت مکتب

**نرم افزار آزاد برای همه**

FreeSMS یک برنامهٔ مدیریت مکتب برای ویندوز است که با ‎.NET 10 اجرا می‌شود. هدف آن فراهم‌کردن محیطی فارسی و راست‌به‌چپ برای نگهداری اطلاعات شاگردان، امور آموزشی و حساب‌های مالی مکتب است. اطلاعات در بانک SQL Server نگهداری می‌شوند و امکان کار با بانک محلی روی همان کمپیوتر وجود دارد.

## امکانات برنامه

- ثبت و مدیریت اطلاعات شاگردان و ثبت‌نام در سال تعلیمی.
- مدیریت پایه‌ها، صنف‌ها، مضامین و آموزگاران.
- ثبت نمرات و تهیهٔ کارنامه و گزارش نتایج.
- مدیریت حضور و غیاب.
- ثبت فیس، پرداخت‌ها، تخفیف‌ها و ماندهٔ حساب شاگردان.
- مدیریت حساب‌های کاربران و سطح دسترسی آن‌ها.
- پیش‌نمایش و چاپ گزارش‌ها، ذخیرهٔ تصویر PNG و خروجی جدولی Excel با قالب XLSX.

## آزادی نرم‌افزار

نرم‌افزار آزاد بر اختیار کاربر در اجرای برنامه، مطالعهٔ سورس، تغییر آن و شریک‌ساختن نسخه‌های اصلی و اصلاح‌شده تأکید دارد. هدف این پروژه، فراهم‌کردن امکان یادگیری و بهبود برنامه بر اساس نیاز مکتب‌ها و کاربران آن است.

دسترسی به سورس کمک می‌کند طرز کار برنامه روشن باشد، مشکلات آن بررسی شوند و توسعه‌دهندگان بتوانند زبان، ظاهر و امکانات آن را بهتر کنند. گزارش خطا، پیشنهاد بهبود، اصلاح مستندات و مشارکت در کدنویسی، راه‌هایی برای کمک به این هدف هستند.

## نصب و اجرا روی ویندوز

### پیش‌نیازها

- ویندوز ۶۴ بیتی؛ برنامه به صورت x86 ساخته می‌شود و روی ویندوز ۶۴ بیتی اجرا می‌شود.
- SQL Server Express LocalDB نسخهٔ ۲۰۱۹ یا جدیدتر برای نگهداری بانک محلی.
- بستهٔ اجرایی کامل برنامه، شامل فایل اجرا، بانک اولیه، قلم‌ها و قالب‌های گزارش.

محیط اجرای ‎.NET 10 همراه بستهٔ مستقل برنامه قرار دارد. SDK فقط برای ساخت برنامه از سورس لازم است.

### مراحل نصب بستهٔ آماده

1. SQL Server Express LocalDB را روی ویندوز نصب کنید.
2. بستهٔ اجرایی برنامه را کامل در یک پوشهٔ تازه استخراج کنید.
3. پوشه‌های همراه، از جمله `original`، `fonts` و `portable-layouts` را کنار فایل اجرا نگه دارید.
4. فایل `FreeSMS.exe` را اجرا کنید.
5. در اجرای نخست، برنامه بانک محلی را آماده می‌کند و صفحهٔ ورود باز می‌شود. با حساب کاربری تعریف‌شده در همان بانک وارد شوید.

خروجی XLSX گزارش‌ها به Office وابسته نیست. بعضی مسیرهای قدیمی واردکردن و صادرکردن Excel در فرم‌ها، به مؤلفه‌های سازگار ۳۲ بیتی Office یا Access نیاز دارند. چاپ گزارش و ذخیره به PDF از پنجرهٔ چاپ ویندوز انجام می‌شود.

## محل نگهداری اطلاعات

بانک محلی در مسیر زیر نگهداری می‌شود:

```text
%LOCALAPPDATA%\free-sms\windows-db\school_af_kbr
```

نمونهٔ اختصاصی LocalDB با نام `(localdb)\FreeSMS` و بانک با نام `school_af_kbr` ساخته می‌شود. اتصال با حساب ویندوز انجام می‌شود. بانک اولیه فقط در نخستین راه‌اندازی کپی می‌شود و بانک موجود با استخراج نسخهٔ تازهٔ برنامه جایگزین نمی‌شود.

برای اتصال به SQL Server موجود با ساختار سازگار، متغیر محیطی `FREE_SMS_CONNECTION_STRING` را تنظیم کنید. برنامه به‌روزرسانی‌های بانک را روی بانک انتخاب‌شده اجرا می‌کند.

## ساخت و اجرا از سورس

1. SDK دات‌نت ۱۰ برای Windows x64 را نصب کنید.
2. سورس کامل پروژه را در یک پوشه قرار دهید.
3. از ریشهٔ پروژه، `setup.cmd` یا `build-windows.cmd` را اجرا کنید.
4. پس از پایان ساخت، `run.cmd` را اجرا کنید یا فایل زیر را باز کنید:

```text
dist\FreeSMS-Net10\FreeSMS.exe
```

دستور معادل ساخت در PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-original-windows.ps1
```

راه‌حل پروژه در `dotnet/FreeSms.slnx` قرار دارد. `preview.cmd` پیش‌نمایش فرم اصلی را بدون اتصال به بانک نشان می‌دهد.

## وضعیت سازگاری و بررسی‌ها

بانک اولیهٔ توزیع‌شده، جدول‌ها و رویه‌های بعضی گزینه‌های انضباطی را ندارد. برنامه هنگام انتخاب این گزینه‌ها سازگاری بانک را بررسی می‌کند و در صورت نبود ساختار لازم، پیام مشخص نشان می‌دهد. استفاده از این بخش‌ها به بانک کامل و سازگار نیاز دارد.

در [آزمون ویندوز](https://github.com/mujtabahassani0101/freesms/actions/runs/41501113977)، رندر ۸۹ فرم و ۹۸ قالب گزارش، راه‌اندازی بانک و ورود، ۱۸ بررسی بانک، ۴۰ بررسی محاسبات گزارش و ۱۳۸ بررسی کنترل‌ها و بسته موفق شدند. در بررسی ۷۷ مسیر منو، ۷۰ صفحه بارگذاری شدند و ۷ مسیر پیام یا پنجرهٔ انتخابِ پاسخ‌گو داشتند؛ خطا یا توقف از سقف انتظار ثبت نشد.

این بررسی‌ها، تأیید همهٔ عملیات با داده‌های واقعی یا همهٔ چاپگرها نیستند. شرح آزمون‌ها و محدودیت‌های آن‌ها در [مدارک بررسی ویندوز](validation/README-native.md) قرار دارد. `check-windows.cmd` بررسی‌های بانک، گزارش، کنترل‌ها، فرم‌ها و ورود را اجرا می‌کند. آزمون جداگانهٔ مسیرهای منو با دستور زیر و بانک موقت انجام می‌شود:

```powershell
FreeSMS.exe --verify-navigation
```

## راهنمای توسعه‌دهندگان

| مسیر | محتوا |
| --- | --- |
| `dotnet/FreeSms.Original.Windows` | فرم‌ها، کنترل‌گرها و منابع برنامهٔ ویندوزی |
| `dotnet/FreeSms.NativeControls` | کنترل‌ها، تقویم، ویرایشگر و نمایش گزارش |
| `dotnet/FreeSms.Reports` | محاسبات، قالب‌ها و خروجی گزارش |
| `dotnet/FreeSms.Core` | اتصال SQL، آماده‌سازی و به‌روزرسانی بانک |
| `analysis/sql-resources` | اسکریپت‌های به‌روزرسانی بانک |
| `original/installed/db` | بانک اولیهٔ همراه برنامه |
| `validation` | شواهد و نتایج بررسی‌ها |

این پروژه از سورس و منابع بازیابی‌شدهٔ `school_af.exe` توسعه یافته است. جزئیات بازیابی و اجزای مرجع قدیمی در [راهنمای بازیابی](dotnet/FreeSms.Original.Windows/RECOVERY.md) و توضیح ساخت فعال در [راهنمای ‎.NET 10](DOTNET10.md) آمده است.

## مشارکت و گزارش مشکل

برای گزارش مشکل، نام صفحه و دکمه، مراحل تکرار خطا و متن پیامی را که نمایش داده می‌شود بنویسید. پیشنهادهای مربوط به زبان، دسترس‌پذیری، گزارش‌ها و روش نصب نیز به بهبود برنامه کمک می‌کنند.
