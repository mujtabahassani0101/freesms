# Free SMS — نسخهٔ ویندوز با .NET 10

نسخهٔ اصلی اجرای این بسته اکنون با **C# 14، .NET 10 و Windows Forms** نوشته شده است. برنامهٔ جدید به Python، کلید سخت‌افزاری، Tiny.ocx یا Wine وابسته نیست. سورس و تنظیمات خارج از `free-sms` تغییر نکرده‌اند.

**همهٔ قابلیت‌های نرم‌افزار قدیمی هنوز بازسازی نشده‌اند.** انتقال حاضر شامل بخش‌هایی است که در نسخهٔ بومی قبلی پیاده‌سازی شده بودند؛ کدهای C# بازیابی‌شدهٔ نسخهٔ اصلی همچنان برای مراجعه حفظ شده‌اند.

## اجرای خروجی آماده

بستهٔ `FreeSMS-Net10-Windows-x64.zip` را در ویندوز x64 استخراج کنید و از داخل پوشهٔ آن `FreeSMS.exe` را باز کنید. تمام فایل‌های کنار EXE باید حفظ شوند؛ محیط .NET همراه این خروجی است و نصب Python یا .NET جداگانه لازم نیست.

- برای مشاهدهٔ رابط بدون بانک، `Preview.cmd` را اجرا کنید.
- برای ثبت اطلاعات، Docker Desktop را باز کنید و سپس `FreeSMS.exe` را اجرا کنید. حالت **Linux containers** با WSL2 لازم است؛ رابط برنامه مستقیماً روی ویندوز اجرا می‌شود و SQL Server داخل Docker است.
- دریافت اولیهٔ تصویر SQL Server به اینترنت نیاز دارد؛ داده‌های برنامه در بانک محلی ذخیره می‌شوند.

ساخت خروجی ویندوز در لینوکس انجام شده است؛ اجرای تعاملی آن روی ویندوز در این محیط بررسی نشده است.

## ساخت از سورس

۱. نسخهٔ به‌روز SDK دات‌نت ۱۰ برای Windows x64 را نصب کنید.

۲. `setup.cmd` را اجرا کنید؛ کتابخانه‌ها بازیابی و برنامه ساخته می‌شود.

۳. `preview.cmd` برای پیش‌نمایش و `run.cmd` برای اجرای کامل است.

۴. برای ساخت خروجی مستقل، `build-windows.cmd` را اجرا کنید. خروجی:

```text
dist\FreeSMS-Net10\FreeSMS.exe
```

پروژهٔ اصلی در `dotnet/FreeSms.slnx` است. دستور معادل از داخل پوشهٔ `dotnet`:

```bat
dotnet publish FreeSms.Windows/FreeSms.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o ../dist/FreeSMS-Net10
```

فرم مشخص در پیش‌نمایش:

```bat
preview.cmd --form frmSabtenam
```

## بخش‌های منتقل‌شده

- نمایش چیدمان و منوهای بازیابی‌شدهٔ ۸۹ فرم با کنترل‌های استاندارد Windows Forms.
- ثبت، ویرایش، جستجو و حذف متعلم، تصویر، فیس‌های ثبت‌نام و ترانسپورت.
- مشخصات مکتب و اطلاعات پایه: صنف، پایه، معلم، راننده، درس، تخفیف، امتحان، حوزه و ایام تعلیمی.
- انتخاب سال تعلیمی، تخصیص معلم به صنف و درس، و تنظیم رنگ.
- راه‌اندازی بانک اولیه و اجرای منابع SQL با بررسی اثر انگشت، ترتیب نسخه‌ها و تراکنش.

ثبت فیس در پروندهٔ متعلم، به معنی تکمیل ماژول حسابداری نیست. همهٔ محاسبات نمره و نتیجه، امور مالی، چاپ و طراحی گزارش‌ها و سایر فرم‌ها هنوز به رابط جدید منتقل و تطبیق داده نشده‌اند. کنترل‌های اختصاصی Janus و گزارش‌سازهای COM در نسخهٔ جدید اجرا نمی‌شوند. هیچ ادعایی دربارهٔ تطابق پیکسلی همهٔ فرم‌ها یا برابری کامل رفتار با نسخهٔ اصلی وجود ندارد.

## بهبودهای فنی

- اجرای عملیات بانک در پس‌زمینه برای پاسخ‌گو ماندن رابط.
- استفادهٔ مجدد از اتصال‌های SQL و نگه‌داری مشخصات ستون‌ها و پارامترهای رویه‌ها در حافظه.
- بارگیری یک‌بارهٔ تعریف فرم‌ها و استفادهٔ مجدد از تصاویر در هر پنجره.
- جدول‌های VirtualMode و مکث ۳۰۰ میلی‌ثانیه‌ای جستجو برای کاهش پردازش هر کلید.
- استفاده از دستورهای پارامتری و تراکنش مشترک برای ثبت متعلم و عکس؛ خطای عکس نیز ثبت متعلم را برمی‌گرداند.
- ثبت نسخهٔ هر به‌روزرسانی SQL در همان تراکنش، برای ادامهٔ صحیح پس از خطا.
- ساخت Release با Tiered PGO و ReadyToRun؛ حذف کدهای استفاده‌نشده با trimming فعال نیست، چون رابط و SQL به اطلاعات زمان اجرا نیاز دارند.

آزمون اندازه‌گیری سرعت در برابر نسخهٔ قبلی انجام نشده است؛ موارد بالا تغییرات پیاده‌سازی‌اند و تضمین درصد معینی از افزایش سرعت نیستند.

## بانک و داده‌ها

| مورد | مقدار |
| --- | --- |
| کانتینر اختصاصی | `free-sms-database` |
| مخزن دادهٔ Docker | `free-sms-data` |
| آدرس | `127.0.0.1:15436` |
| نام بانک | `free_sms` |
| رمز تصادفی و تنظیمات ویندوز | `%LOCALAPPDATA%\free-sms\database.env` |

نسخهٔ .NET از همان بانک مستقل نسخهٔ Python داخل `free-sms` استفاده می‌کند؛ از بانک و تنظیمات پروژهٔ والد استفاده نمی‌کند. فایل تنظیمات و مخزن داده را برای حفظ اطلاعات نگه دارید. SQL Server با تنظیم `MSSQL_PID=Developer` برای توسعه و آزمایش راه‌اندازی می‌شود.

برای اتصال به یک SQL Server موجود با بانک و طرح سازگار، متغیر `FREE_SMS_CONNECTION_STRING` را قبل از اجرا تنظیم کنید. در این حالت برنامه Docker را راه‌اندازی نمی‌کند؛ نام بانک و روش احراز هویت از رشتهٔ اتصال خوانده می‌شود و به‌روزرسانی‌های بانک روی همان بانک اجرا خواهند شد. برای نمونه، اتصال Windows Authentication به بانک آماده:

```bat
set "FREE_SMS_CONNECTION_STRING=Server=localhost;Database=free_sms;Integrated Security=True;Encrypt=True;TrustServerCertificate=True"
run.cmd
```

## ساختار سورس

| مسیر | محتوا |
| --- | --- |
| `dotnet/FreeSms.Core/` | منطق C# بانک، به‌روزرسانی، متعلم و اطلاعات پایه |
| `dotnet/FreeSms.Windows/` | برنامهٔ Windows Forms با هدف `net10.0-windows` |
| `dotnet/FreeSms.Checks/` | بررسی‌های مستقل و آزمون واقعی بانک |
| `native/assets/` | منابع رابط و تصاویر مشترک |
| `analysis/decompiled/` | خروجی کامل C# و RESX و گزارش‌های بازیابی‌شده، برای مراجعه |
| `analysis/sql-resources/` | ۴۴ اسکریپت اصلی به‌روزرسانی بانک |
| `analysis/database/` و `native/sql/` | تعریف‌های بازیابی‌شدهٔ SQL |
| `original/installed/db/` و `original/update/rpt/` | بانک اولیه و منابع لازم برای راه‌اندازی |
| `native/` و `tests/` | سورس و آزمون‌های نسخهٔ قبلی Python |
| `scripts/` | ابزارهای استخراج، تحلیل و بسته‌بندی |
| `validation/` | نتیجهٔ بررسی‌ها |

پروژهٔ قدیمی `analysis/decompiled/school_af.csproj` به دلیل ابهام‌سازی، خروجی ناقص بازیابی و وابستگی‌های قدیمی، پروژهٔ قابل ساخت .NET 10 نیست؛ در ساخت جدید شرکت ندارد. کدهای مرجع آن همچنان بررسی قفل قدیمی را دارند؛ برنامهٔ جدید در `dotnet` هیچ کلید سخت‌افزاری درخواست نمی‌کند.

راهنمای نسخهٔ قبلی در `README-PYTHON.md` است و فایل‌های `setup-python.cmd`، `run-python.cmd`، `preview-python.cmd` و `build-python.cmd` آن را اجرا می‌کنند. محیط مجازی، رمزها، کش NuGet، ابزار خارجی REA و نصب‌کننده‌های اصلی در بستهٔ سورس قرار نمی‌گیرند.

## بررسی

در محیط فعلی ساخت Release و ۱۶ بررسی C# موفق شدند؛ آزمون بانک از کانتینر و مخزن دادهٔ موقت مخصوص خود استفاده کرد و پس از پایان آن‌ها را حذف کرد. اجرای رابط Windows Forms روی ویندوز هنوز بررسی نشده است.

از داخل `dotnet`:

```bat
dotnet run --project FreeSms.Checks/FreeSms.Checks.csproj -c Release -- --root ..
dotnet run --project FreeSms.Checks/FreeSms.Checks.csproj -c Release -- --root .. --integration
```

دستور دوم به Docker نیاز دارد. برای بررسی بانک و رندر همهٔ فرم‌ها روی ویندوز، `check-windows.cmd` را اجرا کنید.

مبنای هدف‌گذاری: [مستندات چارچوب‌های .NET](https://learn.microsoft.com/en-us/dotnet/standard/frameworks/). کتابخانهٔ SQL: [Microsoft.Data.SqlClient](https://www.nuget.org/packages/Microsoft.Data.SqlClient/7.1.1). خروجی مستقل از runtime نسخهٔ 10.0.14 استفاده می‌کند؛ وابستگی PKCS نیز صریحاً روی [10.0.14](https://www.nuget.org/packages/System.Security.Cryptography.Pkcs/10.0.14) قرار گرفته است.
