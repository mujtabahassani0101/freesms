# تصاویر محیط FreeSMS

این پوشه تصاویر نسخهٔ ویندوز را برای نمایش در README نگهداری می‌کند. تصویر صفحهٔ اصلی توسط کاربر ارائه شده است. داده‌های فرم‌ها، نمونه‌های آزمایشی در بانک موقت‌اند و به مکتب یا شاگرد واقعی تعلق ندارند. مربع رنگی در فرم معلومات، نشانگر آزمایشی عکس شاگرد است.

تصاویر بدون تغییر ظاهر، متن یا اطلاعات رابط کپی شده‌اند. منشأ و SHA-256 هر تصویر در [sources.json](sources.json) ثبت شده است.

- `main-window.png`: تصویر صفحهٔ اصلی ارائه‌شده توسط کاربر.
- `students.png`: فهرست شاگردان پس از ثبت و انتخاب رکورد آزمایشی.
- `student-details.png`: فرم اصلاح معلومات شاگرد پس از بازخوانی رکورد ذخیره‌شده.
- `classes.png`: مدیریت صنف‌ها پس از بازخوانی صنف و فیس ذخیره‌شده.

تصاویر فرم‌ها از [اجرای ویندوز ۴۱۵۶۸۷۲۰۷۳۹](https://github.com/mujtabahassani0101/freesms/actions/runs/41568720739) انتخاب شده‌اند.

برای تهیهٔ دوبارهٔ تصاویر فرم‌ها، مسیر `--verify-business-actions` برنامهٔ ویندوزی تصاویر فرم‌های دارای داده را پس از ذخیره و بازخوانی ثبت می‌کند. خروجی‌ها در `navigation-checks` و زیرپوشهٔ `docs-gallery` قرار می‌گیرند؛ گردش کار ویندوز، تصاویر فرم‌ها را در بستهٔ `original-populated-gallery` نگهداری می‌کند.

تصاویر فقط ظاهر بخش نمایش‌داده‌شده را نشان می‌دهند. وضعیت آزمون‌ها و محدودیت‌های برنامه در بخش «وضعیت سازگاری و بررسی‌ها» از README اصلی آمده است.
