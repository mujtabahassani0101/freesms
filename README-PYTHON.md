# Free SMS — سورس نسخهٔ ویندوز بدون کلید سخت‌افزاری

این پوشه یک کپی مستقل از تمام سورس اختصاصی موجود پروژه است: برنامهٔ بومی Python/Qt، کد C# بازیابی‌شده، منابع فرم و گزارش، منطق SQL، ابزارهای تحلیل و آزمون‌ها. برنامه‌ای که با `run-python.cmd` اجرا می‌شود هیچ وابستگی به کلید USB، Tiny.ocx یا Wine ندارد.

**این نسخه هنوز بازسازی کامل همهٔ قابلیت‌های نرم‌افزار اصلی نیست.** نگه‌داری تمام کدهای بازیابی‌شده به معنی انتقال کامل رفتار آن‌ها به برنامهٔ بومی نیست. ثبت و ویرایش متعلم، مشخصات مکتب، اطلاعات پایه، سال تعلیمی و تخصیص معلم پیاده‌سازی شده‌اند؛ عملیات برخی فرم‌ها، محاسبات نمرات، امور مالی و چاپ گزارش‌ها هنوز تکمیل و تطبیق داده نشده‌اند. ۸۹ فرم بازیابی‌شده قابل نمایش‌اند.

## اجرای ویندوز

پیش‌نیازها:

- Windows 10/11 با معماری x64 و Python 3.14 نسخهٔ ۶۴ بیتی، همراه Python Launcher (`py`).
- برای کار با بانک اطلاعاتی: Docker Desktop با WSL2 و حالت **Linux containers**. خود رابط برنامه مستقیماً روی ویندوز اجرا می‌شود؛ SQL Server داخل Docker است.
- اینترنت برای نصب اولیهٔ کتابخانه‌ها و دریافت اولیهٔ تصویر SQL Server؛ پس از دریافت آن‌ها، بانک محلی است.

۱. پوشه را در محل قابل نوشتن استخراج کنید و `setup-python.cmd` را اجرا کنید.

۲. برای مشاهدهٔ رابط، `preview-python.cmd` را اجرا کنید. این حالت فقط‌خواندنی است و به Docker نیاز ندارد.

۳. برای ثبت اطلاعات، Docker Desktop را باز کنید و سپس `run-python.cmd` را اجرا کنید. اجرای نخست، بانک و به‌روزرسانی‌های آن را آماده می‌کند.

برای بازکردن مستقیم فرم ثبت‌نام در پیش‌نمایش:

```bat
preview-python.cmd --form frmSabtenam
```

برای اجرای مستقیم از خط فرمان:

```bat
.venv\Scripts\python.exe -X utf8 native\main.py
```

هیچ کلید سخت‌افزاری یا کد فعال‌سازی برای اجرای این برنامه درخواست نمی‌شود. وابستگی‌ها و تصویر SQL Server مجوزهای مستقل خود را دارند؛ SQL Server در این بسته با ویرایش Developer برای توسعه و آزمایش پیکربندی شده است. برای استفادهٔ عملیاتی باید ویرایش دارای مجوز مناسب انتخاب شود.

## ساخت فایل اجرایی ویندوز

پس از نصب، `build-python.cmd` را **روی ویندوز** اجرا کنید. خروجی مورد انتظار:

```text
dist\FreeSMS\FreeSMS.exe
```

تمام پوشهٔ `dist\FreeSMS` باید همراه برنامه جابه‌جا شود. در خروجی ساخته‌شده Python جداگانه لازم نیست؛ Docker Desktop برای بانک همچنان لازم است. ساخت فایل EXE و اجرای واقعی در ویندوز در محیط فعلی آزمایش نشده است؛ فایل EXE آماده در این بسته وجود ندارد.

## اطلاعات و استقلال این نسخه

| مورد | مقدار |
| --- | --- |
| کانتینر اختصاصی | `free-sms-database` |
| مخزن دادهٔ Docker | `free-sms-data` |
| آدرس بانک | `127.0.0.1:15436` |
| نام بانک | `free_sms` |
| تنظیمات و رمز تولیدشده در ویندوز | `%LOCALAPPDATA%\free-sms\database.env` |

رمز بانک در اولین اجرا به‌صورت تصادفی ساخته می‌شود و داخل سورس نیست. پوشهٔ داده و مخزن Docker را برای نگه‌داری اطلاعات حفظ کنید. این نسخه از تنظیمات و بانک نسخهٔ پوشهٔ والد استفاده نمی‌کند.

## محتویات سورس

| مسیر | محتوا |
| --- | --- |
| `native/` | برنامهٔ قابل اجرای Python/Qt، کنترل‌کننده‌ها و سرویس بانک |
| `native/assets/` | چیدمان ۸۹ فرم، تصاویر، قلم و طرح بانک |
| `analysis/decompiled/` | تمام خروجی موجود C#، پروژهٔ بازیابی‌شده، RESX و قالب‌های گزارش |
| `analysis/ShamsiDate.cs` | سورس بازیابی‌شدهٔ تقویم |
| `analysis/sql-resources/` | ۴۴ اسکریپت SQL به‌روزرسانی و نمایهٔ آن‌ها |
| `analysis/database/` | طرح و تعریف‌های بازیابی‌شدهٔ بانک |
| `original/installed/db/` | کپی بانک اولیه برای راه‌اندازی مستقل |
| `original/update/rpt/` | قالب‌های گزارش مورد استفادهٔ به‌روزرسانی بانک |
| `scripts/` | سورس ابزارهای استخراج و تحلیل قبلی |
| `tests/` | آزمون‌های رابط و جریان‌های ثبت اطلاعات |
| `free-sms.spec` | تعریف ساخت خروجی ویندوز با PyInstaller |
| `SOURCE-MANIFEST.json` | مسیر، اندازه و اثر انگشت فایل‌های تحویلی |
| `validation/RESULTS.md` | دامنه و نتیجهٔ بررسی این کپی |

کدهای `analysis/decompiled` به‌عنوان مرجع حفظ شده‌اند و در اجرای `run-python.cmd` وارد نمی‌شوند. آن کدها هنوز وابستگی‌ها و بررسی قفل نسخهٔ اصلی را دارند و به علت ابهام‌سازی و بازیابی ناقص، پروژهٔ آمادهٔ کامپایل محسوب نمی‌شوند. استقلال از قفل مربوط به برنامهٔ بومی داخل `native` است.

ابزارهای تحلیلی `scripts` آرشیو سورس کارهای قبلی‌اند؛ برخی برای لینوکس یا تحلیل نسخهٔ اصلی نوشته شده‌اند و برای اجرای این نسخه نیاز نیستند. ابزار خارجی REA، نصب‌کننده‌های اصلی، فایل‌های اجرایی اصلی، محیط‌های مجازی، رمزها و خروجی‌های حجیم تحلیل داخل این بسته قرار نگرفته‌اند. سورس اختصاصی برنامه و خروجی بازیابی C# و SQL در این پوشه است.

## اجرای آزمون‌ها در ویندوز

نمایش فرم‌ها، بدون بانک:

```bat
set QT_QPA_PLATFORM=offscreen
.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

آزمون جریان‌های واقعی بانک، با Docker Desktop روشن:

```bat
.venv\Scripts\python.exe -X utf8 tests\integration\test_school_workflows.py
```

آزمون بانک یک بانک موقت با پیشوند `free_sms_test_` ایجاد می‌کند و پس از پایان آن را حذف می‌کند.
