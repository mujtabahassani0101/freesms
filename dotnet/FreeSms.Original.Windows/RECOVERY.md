# سورس بازیابی‌شدهٔ برنامهٔ اصلی

این پروژه همهٔ واحدهای C# بازیابی‌شده از `school_af.exe` نسخهٔ ۱۴۰۲/۱۱/۱۹ و منابع فرم و گزارش همان اسمبلی را وارد ساخت .NET 10 می‌کند. این مسیر با رابط بازسازی‌شدهٔ پروژهٔ `FreeSms.Windows` متفاوت است: منطق و کنترل‌های فرم‌های موجود EXE حفظ شده‌اند.

SHA-256 ورودی: `f380191dc4a7c6fbf7dbc0f95c21e915e9b50bf8a8bd44eac6e8943bc715fe28`.

تغییرات سازگاری:

- بازیابی با ILSpy و referenceهای واقعی .NET 2، Janus، ActiveReports، Crystal و Office انجام شد.
- ۲۱ نام فیلد متداخل با نام متد، و یک enum متداخل، تغییر نام داده شدند؛ ارجاع‌های متناظر نیز اصلاح شدند.
- متدهای Dispose که ابهام‌ساز تغییر نام داده بود، به override متناظر WinForms برگردانده شدند.
- provider قدیمی SQL به Microsoft.Data.SqlClient و OLE DB به بستهٔ .NET 10 منتقل شد؛ SQL و رویه‌های کاری حفظ شده‌اند.
- هفت خواندن کامل فایل به ReadExactly تبدیل شدند تا با قواعد .NET جدید، داده ناقص خوانده نشود.
- منابع اصلی فرم، RPT و licence context کتابخانه‌های همراه حفظ شده‌اند. کتابخانه‌های همراه در `vendor/legacy` هستند.

تغییرات مربوط به قفل:

- کنترل‌ها و ارجاع‌های COM متعلق به Tiny حذف شدند.
- چهار ورودی ارتباط با کلید در asdu و بررسی entitlement ماژول در asdax به حالت بدون سخت‌افزار تبدیل شدند.
- جریان آغاز برنامه، اتصال به بانک بومی و ورود کاربر را انجام می‌دهد؛ کنترل USB، فایل فعال‌سازی و تاریخ اعتبار سخت‌افزار اجرا نمی‌شود.
- ورود کاربر، گذرواژه و مجوزهای منو در asda3/asdaj باقی مانده‌اند؛ هیچ ورود خودکار admin اضافه نشده است.

ساخت:

```text
dotnet publish FreeSms.Original.Windows.csproj -c Release -r win-x86 --self-contained true -o ../../dist/FreeSMS-Original-Net10
```

هدف x86 برای سازگاری با اجزای اصلی ویندوزی حفظ شده است. خروجی `school_Af.exe` نام اسمبلی اصلی را حفظ می‌کند. SQL Server Express LocalDB یک مؤلفهٔ بومی ویندوز است؛ Docker اجرا نمی‌شود.

**وضعیت: ساخت کامل سورس و منابع موفق است؛ سازگاری زمان اجرای کتابخانه‌های قدیمی و برابری همهٔ جریان‌ها هنوز در حال بررسی است.** آزمون `--verify-original-forms` ساخت و نقاشی فرم‌های اصلی را بدون نمایش صفحهٔ ورود بررسی می‌کند و هیچ دسترسی کاربری را تغییر نمی‌دهد. این آزمون به‌تنهایی صحت چاپ، همهٔ گزارش‌ها، محاسبات و ورود واقعی داده را ثابت نمی‌کند.
