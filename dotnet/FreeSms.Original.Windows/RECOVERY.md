# سورس بازیابی‌شدهٔ برنامهٔ اصلی

این پروژه همهٔ واحدهای C# بازیابی‌شده از `school_af.exe` نسخهٔ ۱۴۰۲/۱۱/۱۹ و منابع فرم و گزارش همان اسمبلی را وارد ساخت .NET 10 می‌کند. این مسیر با رابط بازسازی‌شدهٔ پروژهٔ `FreeSms.Windows` متفاوت است: منطق و کنترل‌گرهای فرم‌های موجود EXE حفظ شده‌اند و کنترل‌های قدیمی بازنویسی شده‌اند.

SHA-256 ورودی: `f380191dc4a7c6fbf7dbc0f95c21e915e9b50bf8a8bd44eac6e8943bc715fe28`.

تغییرات سازگاری:

- بازیابی با ILSpy و referenceهای واقعی .NET 2، Janus، ActiveReports، Crystal و Office انجام شد.
- ۲۱ نام فیلد متداخل با نام متد، و یک enum متداخل، تغییر نام داده شدند؛ ارجاع‌های متناظر نیز اصلاح شدند.
- متدهای Dispose که ابهام‌ساز تغییر نام داده بود، به override متناظر WinForms برگردانده شدند.
- provider قدیمی SQL به Microsoft.Data.SqlClient و OLE DB به بستهٔ .NET 10 منتقل شد؛ SQL و رویه‌های کاری حفظ شده‌اند.
- هفت خواندن کامل فایل به ReadExactly تبدیل شدند تا با قواعد .NET جدید، داده ناقص خوانده نشود.
- منابع اصلی فرم، RPT و licence context کتابخانه‌های همراه حفظ شده‌اند. کتابخانه‌های همراه در `vendor/legacy` هستند.

تغییرات مربوط به قفل:

- کنترل‌ها و ارجاع‌های COM متعلق به Tiny حذف شدند.
- چهار ورودی ارتباط با کلید در asdu و بررسی entitlement ماژول در asdax به حالت بدون سخت‌افزار تبدیل شدند.
- جریان آغاز برنامه، اتصال به بانک بومی و ورود کاربر را انجام می‌دهد؛ کنترل USB، فایل فعال‌سازی و تاریخ اعتبار سخت‌افزار اجرا نمی‌شود.
- ورود کاربر، گذرواژه و مجوزهای منو در asda3/asdaj باقی مانده‌اند؛ هیچ ورود خودکار admin اضافه نشده است.

نسخهٔ فعال اکنون همهٔ فرم‌ها، کنترل‌ها، محاسبات، نمایش و چاپ گزارش را داخل همان فرایند .NET 10 اجرا می‌کند. Janus، تقویم و ActiveReports با کنترل‌های C# بازنویسی شده‌اند. ۹۸ قالب گزارش از RPT به XML تبدیل شده‌اند؛ تابع نمرهٔ توصیفی، شرط‌ها، ارتباط زیرگزارش‌ها و شمارنده‌ها از همان منابع خوانده می‌شوند. شش جدول آماری با خروجی موتور اصلی روی دادهٔ مشخص تطبیق داده شده‌اند. ۵۸ تصویر از منابع اصلی بازیابی شده‌اند.

`FreeSms.ReportHost` فقط ابزار یک‌بارهٔ تبدیل و تولید مرجع مقایسه است و در خروجی اجرایی استفاده نمی‌شود. مسیر قبلی Framework برای سابقهٔ بازیابی در مخزن باقی مانده است. فایل‌های licence context اصلی نیز مرجع بازیابی‌اند و در ساخت فعال بارگذاری نمی‌شوند.

از ریشهٔ مخزن `build-windows.cmd` را اجرا کنید. خروجی مستقل و ReadyToRun در `dist/FreeSMS-Net10/FreeSMS.exe` است. هدف x86 برای سازگاری با واردکردن و صادرکردن اصلی Office حفظ شده است. بانک از SQL Server Express LocalDB بومی استفاده می‌کند.

آزمون `--verify-original-forms` ساخت و نقاشی هر ۸۹ فرم را بررسی می‌کند. `--verify-native-startup` آماده‌سازی بانک و بازشدن ورود اصلی را بدون دورزدن ورود بررسی می‌کند. بررسی موتور گزارش و کنترل‌ها در `FreeSms.NativeChecks` و محاسبات در `FreeSms.ReportChecks` است. اجرای موفق این آزمون‌ها به معنی تطبیق دستی همهٔ جریان‌های کاری، همهٔ حالت‌های داده یا چاپگر واقعی نیست. شواهد نسخهٔ جاری در README مخزن و گردش کار Windows هستند.
