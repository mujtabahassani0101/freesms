# بررسی نسخهٔ .NET 10

تاریخ: ۲۰۲۶-۱۱-۰۲

- نسخهٔ C# با SDK 10.0.401 در لینوکس ساخته شد؛ هدف رابط `net10.0-windows` است.
- انتشار مستقل `win-x64` با `PublishReadyToRun=true` موفق بود؛ زمان‌اجرای همراه خروجی، Microsoft.NETCore.App و Microsoft.WindowsDesktop.App نسخهٔ 10.0.14 است.
- هر ۱۶ بررسی مستقل و یکپارچهٔ SQL موفق بود. جزئیات اجرای نهایی در `dotnet-checks.log` است.
- سناریوها شامل ارقام فارسی و عربی، سازگاری رمزگذاری نسخه با Python و .NET قدیمی، مسیر منو، اثر انگشت ۴۴ منبع SQL، به‌روزرسانی تکرارپذیر بانک، اطلاعات مکتب، سال، متعلم، عکس، جمع مبالغ، جنسیت با مقدار صفر، جلوگیری از تکرار، برگشت تراکنش هنگام خطای عکس، تخصیص معلم، اطلاعات پایه و حذف است.
- آزمون‌ها فقط از کانتینر و مخزن موقت با پیشوند `free-sms-dotnet-check-` استفاده کردند و منابع موقت پس از پایان حذف شدند.
- بررسی وابستگی‌های مستقیم و غیرمستقیم با NuGet، پس از ارتقای PKCS به 10.0.14، هیچ بستهٔ آسیب‌پذیر گزارش نکرد. خروجی در `dotnet-dependency-audit.json` است؛ این نتیجه محدود به پایگاه هشدارهای موجود در زمان بررسی است.

اجرای فرمان انتشار از پوشهٔ `dotnet`:

```text
dotnet publish FreeSms.Windows/FreeSms.Windows.csproj -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -o ../dist/FreeSMS-Net10
```

**اجرای تعاملی و رندر واقعی Windows Forms روی ویندوز آزمایش نشده است.** دستور `check-windows.cmd` برای بررسی روی ویندوز آماده است. تصویر `main.png` و گزارش `RESULTS.md` مربوط به نسخهٔ قبلی Python هستند.

این بررسی، کامل بودن همهٔ ماژول‌ها یا برابری کامل با نرم‌افزار قدیمی را ثابت نمی‌کند. اندازه‌گیری مقایسه‌ای سرعت انجام نشده است. تغییرات فایل‌های پروژه فقط داخل `free-sms` است.
