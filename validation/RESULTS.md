# نتیجهٔ بررسی بسته

تاریخ بررسی: ۲۰۲۶-۱۱-۰۲

- هر ۳ آزمون رابط موفق بود؛ آزمون نمایش فرم‌ها هر ۸۹ فرم را ساخت و نمایش داد.
- هر ۶ آزمون یکپارچهٔ SQL Server و Qt موفق بود: به‌روزرسانی بانک، ثبت و ویرایش و حذف متعلم، جستجو و جلوگیری از تکرار، ذخیرهٔ تصویر، اطلاعات پایه، سال تعلیمی، تخصیص معلم و دکمه‌های ثبت در رابط. جزئیات در `workflows.log` است.
- آزمون بانک از کانتینر، مخزن داده و بانک موقت اختصاصی این بررسی استفاده کرد. پس از پایان، کانتینر و مخزن موقت حذف شدند؛ کانتینر یا بانک پروژهٔ والد تغییر داده نشد.
- مسیر اجرای `native/main.py --preview --screenshot` موفق بود؛ تصویر `main.png` نیز بررسی شد.
- تمام فایل‌های Python و تعریف ساخت از نظر دستور زبان بررسی شدند.
- اثر انگشت هر ۴۴ منبع SQL با نمایه تطبیق داشت. کدهای بازیابی C# و SQL، منابع رابط، ابزارهای تحلیل، بانک اولیه و قالب‌های گزارش با فایل‌های مبنا یکسان بودند.

**محیط آزمون لینوکس بود.** فایل‌های CMD، نصب کتابخانه‌ها روی ویندوز و خروجی PyInstaller در ویندوز اجرا نشده‌اند. بسته شامل سورس و دستور ساخت ویندوز است؛ فایل EXE ازپیش‌ساخته ندارد. موفقیت این آزمون‌ها، کامل بودن قابلیت‌ها یا برابری همهٔ رفتارها با نرم‌افزار اصلی را اثبات نمی‌کند.

فقط فایل‌های داخل `free-sms` ساخته یا تغییر داده شدند. سورس، تنظیمات و فایل‌های پوشهٔ والد تغییر نکردند.
